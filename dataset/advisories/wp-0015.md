# CVE-2026-104762: kadence-blocks

Source: NVD record https://nvd.nist.gov/vuln/detail/CVE-2026-104762 (CNA: security@wordfence.com), published 2026-10-10, retrieved 2026-11-02. Text below is the CVE description as published.

The Kadence Blocks — Page Builder Toolkit for Gutenberg Editor plugin for WordPress is vulnerable to Stored Cross-Site Scripting via Block Font Family Attribute in all versions up to, and including, 3.7.12 due to insufficient input sanitization and output escaping. This makes it possible for authenticated attackers, with author-level access and above, to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page. This encoding bypass is only triggered when the "Load Google Fonts Locally" site option (kadence_blocks_font_settings['load_fonts_local']) is enabled, which is not the default configuration.

Affected: up to and including 3.7.12. First release examined as fixed: 3.7.12.1 (the next release after 3.7.12; confirmed only by reading the diff, not by the advisory).
