# CVE-2024-11976: buddypress

Source: NVD record https://nvd.nist.gov/vuln/detail/CVE-2024-11976 (CNA: security@wordfence.com), published 2026-01-23, retrieved 2026-11-02. Text below is the CVE description as published.

The The BuddyPress plugin for WordPress is vulnerable to arbitrary shortcode execution in all versions up to, and including, 14.3.3. This is due to the software allowing users to execute an action that does not properly validate a value before running do_shortcode. This makes it possible for unauthenticated attackers to execute arbitrary shortcodes.

Affected: up to and including 14.3.3. First release examined as fixed: 14.3.4 (the next release after 14.3.3; confirmed only by reading the diff, not by the advisory).
